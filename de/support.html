Support und häufige Fragen

Medipop hat weder Konto noch Server, deshalb kann der Entwickler Ihre Daten weder sehen noch wiederherstellen. Hier finden Sie, wie Sie in den häufigsten Fällen selbst zurechtkommen. Die Menünamen sind die der App auf Deutsch.

Ich habe den Wiederherstellungscode verloren

Es gibt kein Verfahren, ihn neu zu erstellen, und auch der Entwickler kann ihn nicht wiederherstellen: So bleiben die Daten privat.

  • Solange Sie das Telefon haben und die App sich öffnet, sind die Daten da: Sie können sie ganz normal weiter benutzen.
  • Wenn Sie glauben, ihn gespeichert zu haben, aber nicht sicher sind, gehen Sie zu Mehr, Sicherheit, «Code prüfen»: Schreiben oder fügen Sie den gefundenen Code ein, und die App sagt Ihnen, ob es der richtige ist, ohne etwas zu ändern. Suchen Sie auch nach einer Datei namens «Medipop-Wiederherstellungscode.txt» im Passwortmanager, in den Dateien oder in der Cloud.
  • Wenn Sie die Daten über den Familiencode mit dem anderen Elternteil teilen, lassen sich die Sicherungen auch mit diesem Code öffnen, und die Daten könnten auch auf dessen Telefon sein.
  • Wenn Sie den Code und auch das Telefon (oder den Schlüssel im Telefon) verlieren, lassen sich die Daten nicht wiederherstellen.

Bewahren Sie den Code, sobald Sie können, an einem sicheren Ort auf (Passwortmanager, geschützte Datei, Papier an einem verschlossenen Ort).

Ich habe ein neues Telefon: Wie übertrage ich die Daten?
  1. Auf dem alten Telefon: Mehr, «Sicherung und Familie», «Sicherung exportieren» (oder «Sicherung teilen»). Speichern Sie die Datei .medipop dort, wo Sie sie wiederfinden, zum Beispiel in einem Cloud-Ordner, oder senden Sie sie an sich selbst.
  2. Halten Sie den Wiederherstellungscode des alten Telefons bereit.
  3. Auf dem neuen Telefon: Installieren Sie Medipop (das Telefon muss eine Bildschirmsperre haben), tippen Sie dann auf dem Begrüssungsbildschirm auf «Aus einer Sicherung wiederherstellen». Wählen Sie die Datei und geben Sie den Wiederherstellungscode des alten Telefons ein (oder den Familiencode).
  4. Medipop erstellt einen neuen Tresor mit einem neuen Wiederherstellungscode: Speichern Sie ihn, denn ab jetzt gilt dieser.

Erstellen Sie die Sicherung, bevor Sie das Telefon wechseln: Wenn das alte schon verloren ist und Sie keine Sicherung haben, lassen sich die Daten nicht wiederherstellen.

Wie tausche ich die Daten mit dem anderen Elternteil aus?
  1. Auf dem ersten Telefon: Mehr, «Sicherung und Familie», «Familiencode erstellen». Senden Sie ihn dem anderen Elternteil mit «Senden», oder kopieren Sie ihn oder speichern Sie ihn als Datei. Am besten mündlich oder in einer anderen Nachricht als dem Chat, in dem Sie die Sicherungen senden: Wer den Code und eine Sicherung hat, kann die Daten lesen.
  2. Auf dem anderen Telefon: Mehr, «Sicherung und Familie», «Einer Familie beitreten», «Einfügen» (oder «Aus Datei laden»).
  3. Jetzt lässt sich eine von einem erstellte Sicherung auf dem anderen Telefon öffnen. Mit «Sicherung teilen» senden Sie sie mit der App Ihrer Wahl (WhatsApp, E-Mail, Drive...); der andere öffnet sie mit «Mit Medipop öffnen» oder über «Sicherung importieren».
  4. Vor dem Import sehen Sie eine Vorschau dessen, was sich ändern würde. Wenn zwei Profile dasselbe zu sein scheinen, fragt Sie die App. Die Daten werden zusammengeführt, nicht blind überschrieben: Bei geänderten Einträgen gilt die jüngste Änderung.

Wenn Sie versehentlich etwas importieren, stellt «Letzten Import rückgängig machen» den vorherigen Zustand wieder her (die Sicherheitskopie bleibt 7 Tage erhalten).

Wenn der andere Elternteil die Sicherungen nicht mehr lesen können soll: Verlassen Sie die Familie, erstellen Sie einen neuen Code und geben Sie ihn nur denen, die Sie möchten. Die bereits mit dem alten Code gespeicherten Sicherungen bleiben für diejenigen lesbar, die ihn kennen.

Wie lösche ich alles?
  • Ein Eintrag: Öffnen Sie ihn und wählen Sie «Diesen Eintrag löschen». Ein Profil mit seinem ganzen Verlauf: im Reiter Familie «Profil löschen». Das lässt sich nicht rückgängig machen.
  • Alles auf dem Telefon: Deinstallieren Sie die App. Die Daten werden zusammen mit ihr gelöscht.
  • Die Sicherungen, die Sie erstellt haben, bleiben dort, wo Sie sie gespeichert oder hingesendet haben (Datei, Cloud, Chat, E-Mail): Löschen Sie sie dort.
  • Wenn Sie auch die E-Mails löschen möchten, die Sie dem Entwickler gesendet haben, schreiben Sie an medipop.app@gmail.com.
Wie melde ich ein Problem oder mache einen Vorschlag?

In der App: Mehr, «Problem oder Vorschlag». Wählen Sie die Art, schreiben Sie einen Titel und den Text. Die App öffnet Ihre E-Mail-App mit der fertigen Nachricht, adressiert an medipop.app@gmail.com: Lesen Sie sie und senden Sie sie selbst. Von allein geht nichts raus.

Die Nachricht enthält Ihren Text und einen technischen Block (Version der App, System, Sprache, Name des Bildschirms). Wenn Sie möchten, können Sie ein kurzes technisches Protokoll anhängen, das nur Namen von Bildschirmen und Fehlerarten zeigt. Alle Einzelheiten stehen in der Datenschutzerklärung.

Schreiben Sie keine Gesundheitsdaten und keine Namen in die Nachricht. Beschreiben Sie, was Sie getan haben und was passiert ist, ohne die Inhalte. Wenn Sie keine E-Mail-App haben, schreiben Sie an medipop.app@gmail.com.

Die App sagt mir, ich solle eine Bildschirmsperre einrichten

Medipop schützt die Daten mit dem vom System des Telefons verwahrten Schlüssel und braucht dafür, dass das Telefon eine PIN, ein Muster, ein Passwort oder einen Fingerabdruck hat (oder Face ID, beim iPhone). Richten Sie die Sperre in den Sicherheitseinstellungen des Telefons ein und kehren Sie in die App zurück: Sie prüft von selbst erneut.

Erinnert mich Medipop an Medikamente? Kann sie Dosierungen berechnen?

Erinnerungen ja: Sie wählen die Uhrzeit und für welche Familienmitglieder Sie die Benachrichtigung erhalten, die nie das Medikament zeigt: Höchstens steht der Vorname des Familienmitglieds darin, ohne Nachnamen, und Sie können ihn unter Mehr, Benachrichtigungen ausblenden. Dosierungen nein: Medipop bewahrt nur auf, was Sie schreiben, die Dosis ist der Text, den Sie von der Packung oder vom Rezept abschreiben, und die App berechnet oder prüft sie nicht. Fotos oder Dokumente lassen sich nicht speichern, und sie gibt keine medizinischen Ratschläge. Wenden Sie sich dafür an den Arzt, den Apotheker oder den Tierarzt.
