Assistance et questions fréquentes

Medipop n'a ni compte ni serveur : le développeur ne peut donc ni voir ni récupérer vos données. Vous trouverez ici comment vous en sortir seul dans les cas les plus courants. Les noms des menus sont ceux de l'app en français.

J'ai perdu le code de récupération

Il n'existe aucune procédure pour le refaire, et le développeur ne peut pas non plus le récupérer : c'est ainsi que les données restent privées.

  • Tant que vous avez le téléphone et que l'app s'ouvre, les données sont là : vous pouvez continuer à l'utiliser normalement.
  • Si vous pensez l'avoir enregistré mais n'en êtes pas sûr, allez dans Plus, Sécurité, « Vérifier le code » : écrivez ou collez le code que vous avez trouvé et l'app vous dit si c'est le bon, sans rien changer. Cherchez aussi un fichier nommé « Medipop-code-de-recuperation.txt » dans le gestionnaire de mots de passe, dans les fichiers ou dans le cloud.
  • Si vous partagez les données avec l'autre parent par le code famille, les sauvegardes s'ouvrent aussi avec ce code, et les données peuvent aussi se trouver sur son téléphone.
  • Si vous perdez le code et aussi le téléphone (ou la clé qu'il contient), les données ne peuvent pas être récupérées.

Dès que vous le pourrez, conservez le code en lieu sûr (gestionnaire de mots de passe, fichier protégé, papier dans un endroit réservé).

J'ai un nouveau téléphone : comment transférer les données ?
  1. Sur l'ancien téléphone : Plus, « Sauvegarde et famille », « Exporter la sauvegarde » (ou « Partager la sauvegarde »). Enregistrez le fichier .medipop là où vous pourrez le retrouver, par exemple dans un dossier cloud, ou envoyez-le-vous à vous-même.
  2. Gardez à portée de main le code de récupération de l'ancien téléphone.
  3. Sur le nouveau téléphone : installez Medipop (le téléphone doit avoir un verrouillage d'écran), puis, sur l'écran de bienvenue, touchez « Restaurer depuis une sauvegarde ». Choisissez le fichier et écrivez le code de récupération de l'ancien téléphone (ou le code famille).
  4. Medipop crée un coffre-fort nouveau, avec un nouveau code de récupération : enregistrez-le, car c'est désormais celui qui compte.

Faites la sauvegarde avant de changer de téléphone : si l'ancien est déjà perdu et que vous n'avez aucune sauvegarde, les données ne peuvent pas être récupérées.

Comment échanger les données avec l'autre parent ?
  1. Sur le premier téléphone : Plus, « Sauvegarde et famille », « Créer le code famille ». Envoyez-le à l'autre parent avec « Envoyer », ou copiez-le ou enregistrez-le dans un fichier. De préférence de vive voix ou dans un message différent de la discussion où vous enverrez les sauvegardes : qui a le code et une sauvegarde peut lire les données.
  2. Sur l'autre téléphone : Plus, « Sauvegarde et famille », « Rejoindre une famille », « Coller » (ou « Charger depuis un fichier »).
  3. Désormais, une sauvegarde faite par l'un s'ouvre sur l'autre. Avec « Partager la sauvegarde », vous l'envoyez avec l'app que vous préférez (WhatsApp, messagerie, Drive...) ; l'autre l'ouvre avec « Ouvrir avec Medipop » ou depuis « Importer une sauvegarde ».
  4. Avant d'importer, vous voyez un aperçu de ce qui changerait. Si deux profils semblent identiques, l'app vous le demande. Les données se fusionnent, elles ne sont pas écrasées à l'aveugle : pour celles qui ont été modifiées, c'est la modification la plus récente qui l'emporte.

Si vous importez quelque chose par erreur, « Annuler le dernier import » remet les choses comme avant (la sauvegarde de sécurité est conservée 7 jours).

Si l'autre parent ne doit plus pouvoir lire les sauvegardes : quittez la famille, créez un nouveau code et ne le donnez qu'à qui vous voulez. Les sauvegardes déjà enregistrées avec l'ancien code restent lisibles par ceux qui le connaissent.

Comment tout supprimer ?
  • Une entrée : ouvrez-la et choisissez « Supprimer cette entrée ». Un profil avec tout son historique : depuis l'onglet Famille, « Supprimer le profil ». Cela ne peut pas être annulé.
  • Tout sur le téléphone : désinstallez l'app. Les données sont supprimées avec elle.
  • Les sauvegardes que vous avez créées restent là où vous les avez enregistrées ou envoyées (fichier, cloud, discussion, messagerie) : supprimez-les de là.
  • Si vous voulez aussi supprimer les e-mails que vous avez envoyés au développeur, écrivez à medipop.app@gmail.com.
Comment signaler un problème ou faire une suggestion ?

Dans l'app : Plus, « Problème ou suggestion ». Choisissez le type, écrivez un titre et le texte. L'app ouvre votre application de messagerie avec le message déjà prêt, adressé à medipop.app@gmail.com : relisez-le et envoyez-le vous-même. Rien ne part tout seul.

Le message contient votre texte et un bloc technique (version de l'app, système, langue, nom de l'écran). Si vous le souhaitez, vous pouvez joindre un court journal technique, qui montre seulement des noms d'écrans et des types d'erreurs. Tous les détails sont dans la politique de confidentialité.

N'écrivez ni données de santé ni noms dans le message. Décrivez ce que vous avez fait et ce qui s'est passé, sans les contenus. Si vous n'avez pas d'application de messagerie, écrivez à medipop.app@gmail.com.

L'app me demande de définir un verrouillage d'écran

Medipop protège les données avec la clé gardée par le système du téléphone et a besoin que le téléphone ait un code PIN, un schéma, un mot de passe ou une empreinte (ou Face ID, sur iPhone). Définissez le verrouillage dans les réglages de sécurité du téléphone et revenez dans l'app : elle revérifie toute seule.

Medipop me rappelle-t-elle les médicaments ? Peut-elle calculer les doses ?

Les rappels, oui : vous choisissez l'heure et pour quels membres de la famille recevoir la notification, qui n'affiche jamais le médicament : au plus il y a le prénom du membre de la famille, sans nom de famille, et vous pouvez le masquer dans Plus, Notifications. Les doses, non : Medipop conserve seulement ce que vous écrivez, la dose est le texte que vous recopiez de la boîte ou de l'ordonnance, et l'app ne la calcule ni ne la contrôle. On ne peut pas enregistrer de photos ou de documents, et elle ne donne pas de conseils médicaux. Pour ces choses, adressez-vous au médecin, au pharmacien ou au vétérinaire.
