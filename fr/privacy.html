Politique de confidentialité

Dernière mise à jour : 27 novembre 2026. La version italienne est l'original ; ceci en est une traduction.

En bref : les données que vous écrivez dans Medipop restent sur votre téléphone, chiffrées. Le développeur ne les reçoit pas, ne peut pas les lire et n'a aucun serveur pour les conserver. La seule chose qui peut lui parvenir est un e-mail que vous décidez de lui écrire.

Qui est le développeur

Medipop est développée par Vanni M., développeur individuel. Contact pour la confidentialité et l'assistance : medipop.app@gmail.com.

Les données que vous saisissez dans l'app

Medipop conserve ce que vous écrivez : personnes et animaux, maladies, consultations, traitements, vaccinations, médicaments achetés, notes et, à partir de la version 1.1, certificats médicaux avec les photos de leurs pages. Ce sont des données de santé, et l'app les traite donc avec un soin particulier :

  • elles restent uniquement sur votre téléphone, dans une base de données chiffrée (AES-256, SQLCipher) ;
  • l'app n'a pas accès à internet (elle n'a pas l'autorisation de se connecter) et n'a ni compte ni serveur ;
  • il n'y a ni analyse d'usage, ni publicité, ni suivi, ni bibliothèque tierce qui collecte des données ;
  • la clé qui les ouvre est gardée par le système du téléphone (Android Keystore, Trousseau d'iOS) et par un code de récupération que vous seul connaissez. Le développeur n'a ni la clé ni le code.

Comme ces données sont traitées par vous, à des fins exclusivement personnelles ou domestiques (le dossier de votre famille), ce n'est pas le développeur qui les traite : la réglementation sur la protection des données ne s'applique pas à cet usage (article 2, paragraphe 2, point c, du règlement UE 2016/679, RGPD ; article 2, alinéa 2, lettre a, de la loi fédérale suisse sur la protection des données, nLPD). Le développeur ne traite pas de données personnelles des utilisateurs de l'app, à l'exception des e-mails décrits plus bas.

Enfants

Medipop est conçue pour les adultes. Les parents peuvent saisir les données de santé de leurs enfants dans leur propre dossier de famille, comme dans un carnet privé : l'app ne s'adresse pas aux mineurs, ne demande pas leur âge et ne crée pas de compte pour eux.

Photos des certificats et lecture du texte (à partir de la version 1.1)

À partir de la version 1.1, vous pouvez conserver des certificats médicaux dans Medipop et ajouter des pages à chacun : vous les photographiez, choisissez une photo dans la galerie ou importez un PDF.

  • Appareil photo : sur Android, c'est l'app appareil photo du téléphone qui prend la photo et Medipop ne demande aucune autorisation pour l'appareil photo ; sur iPhone, Medipop demande l'autorisation d'utiliser l'appareil photo la première fois que vous photographiez.
  • Conservation : chaque page est enregistrée comme une image ré-encodée, sans données de localisation ni de l'appareil photo (EXIF), et chiffrée sur le téléphone (AES-256-GCM, une clé par page), dans le même dossier protégé que la base de données. Les fichiers temporaires sont supprimés immédiatement.
  • Lecture du texte : Medipop lit le texte des pages sur le téléphone, sans internet : sur iPhone avec le framework Vision d'Apple, sur Android avec la reconnaissance de texte ML Kit de Google, dont le modèle se trouve dans l'app. Rien n'est envoyé à Apple, à Google ni au développeur (l'app n'a pas l'autorisation d'accéder à internet). À partir du texte, Medipop propose le type, la date de délivrance, la validité, les dates et les jours d'absence et le médecin ; vous confirmez ou corrigez chaque valeur. Le texte reconnu est conservé dans la base de données chiffrée et peut être recherché dans le journal.
  • « Partager en PDF » crée un PDF avec les pages et ouvre la feuille de partage du téléphone. Une fois partagé, le PDF est en dehors de Medipop et n'est pas chiffré : celui qui le reçoit peut le lire. Le PDF temporaire est ensuite supprimé du téléphone.

Les sauvegardes

Une sauvegarde est un fichier chiffré .medipop. C'est vous qui la créez, et c'est vous qui choisissez où elle va : la fenêtre d'enregistrement du téléphone, ou la feuille de partage (WhatsApp, messagerie, Drive...). Medipop ne l'envoie à personne d'elle-même. Le fichier est chiffré : celui qui le reçoit ne l'ouvre qu'avec Medipop et votre code de récupération ou le code famille. À partir de ce moment, le fichier est sous le contrôle du service que vous avez choisi (par exemple votre messagerie ou votre cloud) et de ses conditions ; celui qui gère le service peut voir que le fichier existe, sa taille et à qui vous l'avez envoyé, mais pas son contenu. Les sauvegardes que vous créez restent là où vous les avez mises tant que vous ne les supprimez pas.

Les fiches des certificats voyagent dans les sauvegardes chiffrées .medipop comme les autres entrées, mais pour l'instant les photos des pages ne sont pas dans les sauvegardes : elles restent uniquement sur le téléphone où vous les avez ajoutées.

Le code famille permet aux téléphones de deux parents de lire les sauvegardes l'un de l'autre. Qui a le code et une sauvegarde peut lire les données : ne le donnez qu'à des personnes de confiance.

Supprimer les données

  • Vous pouvez supprimer une seule entrée ou un profil entier depuis l'app.
  • Si vous désinstallez l'app, toutes les données sur ce téléphone sont supprimées.
  • Les sauvegardes que vous avez créées restent là où vous les avez enregistrées ou envoyées : c'est à vous de les supprimer, là.
  • Il n'existe aucune archive chez le développeur auprès de laquelle demander la suppression des données de l'app.

Les e-mails que vous choisissez d'envoyer

Dans le menu « Plus », vous pouvez choisir « Problème ou suggestion ». Medipop n'envoie rien d'elle-même : elle prépare un message et ouvre votre application de messagerie, et c'est vous qui le lisez et l'envoyez, si vous le souhaitez, à medipop.app@gmail.com. Vous pouvez aussi écrire à cette adresse pour une question, sans passer par l'app.

Ce que contient le message préparé par l'app

  • L'objet : « [Medipop version] titre », avec le titre que vous écrivez (160 caractères au maximum).
  • Le texte que vous écrivez (4000 caractères au maximum).
  • Un bloc d'informations techniques, que vous pouvez voir et qui reste dans le message : type (problème ou suggestion), version et numéro de build de l'app, système (Android ou iOS) et version du système, langue, nom de l'écran où vous étiez. Aucune donnée saisie dans l'app.
  • Seulement si vous cochez « Joindre le journal technique » : un court journal en mémoire (3000 caractères au maximum, les plus récents) avec les noms des écrans et les types d'erreurs, nettoyé des mots de passe, adresses e-mail, codes de récupération et longues suites de chiffres. Avant l'envoi, l'app vous montre ce qui sera joint. Il ne contient ni données de santé ni ce que vous avez écrit dans les formulaires.

En outre, comme pour tout e-mail, le message arrive avec votre adresse e-mail et, s'il figure dans le compte, votre nom. Votre fournisseur de messagerie le traite selon ses propres règles.

Merci de ne pas écrire de données de santé (noms, maladies, médicaments, diagnostics) ni d'autres données personnelles dans le message, et de ne pas joindre de fichiers contenant ces données. Le message contient tout ce que vous décidez d'écrire : si vous y mettez des données de santé, elles parviennent au développeur. Si cela arrive par erreur, nous vous demandons de nous le dire et nous les supprimerons.

Vos droits

Pour les e-mails que vous nous avez envoyés, vous pouvez demander l'accès, la rectification, l'effacement, la limitation, l'opposition et, lorsque cela s'applique, la portabilité des données : il suffit d'écrire à medipop.app@gmail.com. Nous répondrons dans un délai d'un mois. Vous avez aussi le droit de vous adresser à l'autorité de contrôle : en Italie, le Garante per la protezione dei dati personali (garanteprivacy.it) ; en Suisse, le Préposé fédéral à la protection des données et à la transparence (PFPDT, edoeb.admin.ch).

Apple et Google

Lorsque vous téléchargez l'app, Apple (App Store) ou Google (Google Play) traitent les données de votre téléchargement et de votre compte selon leurs propres politiques. Le développeur reçoit d'eux, au plus, des statistiques agrégées et anonymes (nombre d'installations, versions, pays). Medipop ne leur envoie aucune donnée et n'en reçoit aucune de l'app. Les bibliothèques de reconnaissance de texte d'Apple (Vision) et de Google (ML Kit) fonctionnent sur le téléphone et Medipop ne leur envoie rien.

Ce site

medipop.app est un site de pages statiques uniquement, hébergé par OVHcloud en France : pas de cookies, pas de statistiques, pas de scripts, pas de contenu d'autres sites. Comme tout serveur web, celui d'OVHcloud enregistre dans ses journaux techniques l'adresse IP et la page demandée, pour la sécurité et le fonctionnement du service, et les conserve selon ses propres règles. Le développeur n'utilise pas ces journaux à d'autres fins.

Sécurité

Chiffrement AES-256 de la base de données et des fichiers de sauvegarde ; les pages des certificats sont chiffrées comme la base de données (AES-256-GCM, une clé par page) ; clés dans le système de protection du téléphone ; verrouillage de l'app par empreinte ou code PIN ; aucune capture d'écran possible pendant que l'app est ouverte (sur Android) et aucun aperçu dans les apps récentes. Aucun système n'est parfait : si le téléphone est « rooté » ou débridé (jailbreak), ou si quelqu'un connaît votre code de récupération et a l'une de vos sauvegardes, il peut lire les données. Si vous perdez le code de récupération et aussi le téléphone, personne, pas même le développeur, ne peut vous rendre les données.

Sources de la liste des médicaments

La liste des noms de médicaments dans l'app est établie à partir de sources publiques (voir la page d'accueil). Elle fonctionne sans se connecter à aucun service.

Modifications de cette politique

Si quelque chose change, nous mettrons à jour cette page et la date en haut. Un changement concernant la manière dont l'app traite les données serait aussi indiqué dans les notes de version.
