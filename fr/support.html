Assistance et questions fréquentes

Medipop n'a ni compte ni serveur : le développeur ne peut donc ni voir ni récupérer vos données. Vous trouverez ici comment vous en sortir seul dans les cas les plus courants. Les noms des menus sont ceux de l'app en français.

J'ai perdu le code de récupération

Il n'existe aucune procédure pour le refaire, et le développeur ne peut pas non plus le récupérer : c'est ainsi que les données restent privées.

  • Tant que vous avez le téléphone et que l'app s'ouvre, les données sont là : vous pouvez continuer à l'utiliser normalement.
  • Si vous pensez l'avoir enregistré mais n'en êtes pas sûr, allez dans Plus, Sécurité, « Vérifier le code » : écrivez ou collez le code que vous avez trouvé et l'app vous dit si c'est le bon, sans rien changer. Cherchez aussi un fichier nommé « Medipop-code-de-recuperation.txt » dans le gestionnaire de mots de passe, dans les fichiers ou dans le cloud.
  • Si vous partagez les données avec l'autre parent par le code famille, les sauvegardes s'ouvrent aussi avec ce code, et les données peuvent aussi se trouver sur son téléphone.
  • Si vous perdez le code et aussi le téléphone (ou la clé qu'il contient), les données ne peuvent pas être récupérées.

Dès que vous le pourrez, conservez le code en lieu sûr (gestionnaire de mots de passe, fichier protégé, papier dans un endroit réservé).

J'ai un nouveau téléphone : comment transférer les données ?
  1. Sur l'ancien téléphone : Plus, « Sauvegarde et famille », « Exporter la sauvegarde » (ou « Partager la sauvegarde »). Enregistrez le fichier .medipop là où vous pourrez le retrouver, par exemple dans un dossier cloud, ou envoyez-le-vous à vous-même.
  2. Gardez à portée de main le code de récupération de l'ancien téléphone.
  3. Sur le nouveau téléphone : installez Medipop (le téléphone doit avoir un verrouillage d'écran), puis, sur l'écran de bienvenue, touchez « Restaurer depuis une sauvegarde ». Choisissez le fichier et écrivez le code de récupération de l'ancien téléphone (ou le code famille).
  4. Medipop crée un coffre-fort nouveau, avec un nouveau code de récupération : enregistrez-le, car c'est désormais celui qui compte.

Faites la sauvegarde avant de changer de téléphone : si l'ancien est déjà perdu et que vous n'avez aucune sauvegarde, les données ne peuvent pas être récupérées.

Comment échanger les données avec l'autre parent ?
  1. Sur le premier téléphone : Plus, « Sauvegarde et famille », « Créer le code famille ». Envoyez-le à l'autre parent avec « Envoyer », ou copiez-le ou enregistrez-le dans un fichier. De préférence de vive voix ou dans un message différent de la discussion où vous enverrez les sauvegardes : qui a le code et une sauvegarde peut lire les données.
  2. Sur l'autre téléphone : Plus, « Sauvegarde et famille », « Rejoindre une famille », « Coller » (ou « Charger depuis un fichier »).
  3. Désormais, une sauvegarde faite par l'un s'ouvre sur l'autre. Avec « Partager la sauvegarde », vous l'envoyez avec l'app que vous préférez (WhatsApp, messagerie, Drive...) ; l'autre l'ouvre avec « Ouvrir avec Medipop » ou depuis « Importer une sauvegarde ».
  4. Avant d'importer, vous voyez un aperçu de ce qui changerait. Si deux profils semblent identiques, l'app vous le demande. Les données se fusionnent, elles ne sont pas écrasées à l'aveugle : pour celles qui ont été modifiées, c'est la modification la plus récente qui l'emporte.

Si vous importez quelque chose par erreur, « Annuler le dernier import » remet les choses comme avant (la sauvegarde de sécurité est conservée 7 jours).

Si l'autre parent ne doit plus pouvoir lire les sauvegardes : quittez la famille, créez un nouveau code et ne le donnez qu'à qui vous voulez. Les sauvegardes déjà enregistrées avec l'ancien code restent lisibles par ceux qui le connaissent.

Comment tout supprimer ?
  • Une entrée : ouvrez-la et choisissez « Supprimer cette entrée ». Un profil avec tout son historique : depuis l'onglet Famille, « Supprimer le profil ». Cela ne peut pas être annulé.
  • Tout sur le téléphone : désinstallez l'app. Les données sont supprimées avec elle.
  • Les sauvegardes que vous avez créées restent là où vous les avez enregistrées ou envoyées (fichier, cloud, discussion, messagerie) : supprimez-les de là.
  • Si vous voulez aussi supprimer les e-mails que vous avez envoyés au développeur, écrivez à medipop.app@gmail.com.
Comment signaler un problème ou faire une suggestion ?

Dans l'app : Plus, « Problème ou suggestion ». Choisissez le type, écrivez un titre et le texte. L'app ouvre votre application de messagerie avec le message déjà prêt, adressé à medipop.app@gmail.com : relisez-le et envoyez-le vous-même. Rien ne part tout seul.

Le message contient votre texte et un bloc technique (version de l'app, système, langue, nom de l'écran). Si vous le souhaitez, vous pouvez joindre un court journal technique, qui montre seulement des noms d'écrans et des types d'erreurs. Tous les détails sont dans la politique de confidentialité.

N'écrivez ni données de santé ni noms dans le message. Décrivez ce que vous avez fait et ce qui s'est passé, sans les contenus. Si vous n'avez pas d'application de messagerie, écrivez à medipop.app@gmail.com.

L'app me demande de définir un verrouillage d'écran

Medipop protège les données avec la clé gardée par le système du téléphone et a besoin que le téléphone ait un code PIN, un schéma, un mot de passe ou une empreinte (ou Face ID, sur iPhone). Définissez le verrouillage dans les réglages de sécurité du téléphone et revenez dans l'app : elle revérifie toute seule.

Medipop me rappelle-t-elle les médicaments ? Peut-elle calculer les doses ?

Les rappels, oui : vous choisissez l'heure et pour quels membres de la famille recevoir la notification, qui n'affiche jamais le médicament : au plus il y a le prénom du membre de la famille, sans nom de famille, et vous pouvez le masquer dans Plus, Notifications. À partir de la version 1.2, un avis signale aussi les boîtes de la pharmacie familiale qui arrivent bientôt à expiration, toujours sans nommer le médicament. Les doses, non : Medipop conserve seulement ce que vous écrivez, la dose est le texte que vous recopiez de la boîte ou de l'ordonnance, et l'app ne la calcule ni ne la contrôle. On ne peut pas enregistrer d'autres photos ou documents que les pages des certificats médicaux et les photos des cartes (à partir de la version 1.1), les pages des ordonnances et les photos des boîtes (à partir de la version 1.2), et elle ne donne pas de conseils médicaux. Elle ne vérifie pas les interactions et ne dit pas à quoi sert un médicament. Pour ces choses, adressez-vous au médecin, au pharmacien ou au vétérinaire.

Puis-je conserver des certificats médicaux ?

Oui, à partir de la version 1.1. Medipop a une archive des certificats médicaux de chaque personne ou animal : sport (en compétition et hors compétition), arrêt de travail, absence scolaire, aptitude (travail, conduite, autre) et autres. Pour en ajouter un, allez dans « Ajouter au journal », « Certificat médical », puis ajoutez les pages avec « Photographier », « Depuis la galerie » ou « Importer un PDF ». Sur Android, c'est l'app appareil photo du téléphone qui prend la photo et Medipop ne demande aucune autorisation pour l'appareil photo ; sur iPhone, elle la demande la première fois que vous photographiez.

  • Les pages sont chiffrées sur le téléphone et enregistrées sans données de localisation.
  • Medipop lit le texte sur le téléphone, sans internet, et propose le type, les dates, l'absence et le médecin : vous confirmez ou corrigez chaque valeur. Le texte peut être recherché dans le journal.
  • Le rappel d'expiration est facultatif : le jour même ou 7, 15, 30 ou 60 jours avant. La notification ne dit pas de quel certificat il s'agit : au plus il y a le prénom du membre de la famille, que vous pouvez masquer dans Plus, Notifications.
  • « Partager en PDF » crée un PDF des pages et ouvre la feuille de partage. Le PDF partagé n'est pas chiffré : celui qui le reçoit peut le lire.
  • Les fiches des certificats sont dans les sauvegardes chiffrées .medipop comme les autres entrées. À partir de la version 1.1, la sauvegarde peut aussi contenir les photos des pages : vous le choisissez avec un interrupteur.

Une copie conservée dans Medipop ne remplace pas le document original : gardez l'original. Medipop n'interprète pas les certificats et ne donne pas de conseils médicaux.

Comment ajouter une carte ?

À partir de la version 1.1. Allez dans Plus, « Cartes » et ajoutez une carte. Pour le recto, touchez « Photographier » ou « Depuis la galerie » ; puis faites de même pour le verso, si besoin.

Medipop lit sur le téléphone, sans internet, les données et le code-barres, et enregistre tout de suite la carte. Tant que vous n'avez pas regardé les données, la carte reste signalée comme à vérifier : ouvrez-la et vérifiez que les données lues sont justes.

Comment montrer le code-barres au comptoir ?

À partir de la version 1.1. Ouvrez la carte et touchez « Afficher le code » : le code-barres réapparaît en grand et l'écran passe à la luminosité maximale.

La photo d'une carte est une copie pratique : elle ne remplace pas la carte là où il faut la puce ou la bande magnétique, ni la carte européenne d'assurance maladie à l'étranger.

Comment partager uniquement les données d'un enfant ?

À partir de la version 1.1, avec un cercle : les personnes et les animaux que vous choisissez, dans n'importe quelle combinaison (un seul enfant, deux personnes, même seulement le chien), partagés avec quelqu'un. Vous pouvez avoir plusieurs cercles, chacun avec son propre code et son propre choix de qui partager.

  1. Allez dans Plus, « Sauvegarde et famille », « Cercles de partage », « Créer un cercle ». Donnez un nom au cercle et choisissez qui partager.
  2. Envoyez le code du cercle à l'autre parent, une seule fois. De préférence pas dans la même discussion que celle où vous enverrez les sauvegardes.
  3. Ensuite, touchez « Partager la sauvegarde » (ou « Exporter la sauvegarde ») et choisissez à qui elle est destinée : le cercle. Vous pouvez aussi y modifier qui en fait partie. La sauvegarde ne contient que les personnes et les animaux du cercle.
  4. L'autre parent, dans les cercles de partage, touche « Rejoindre un cercle » et colle le code. Puis il ouvre le fichier avec « Ouvrir avec Medipop ».

Celui qui a le code du cercle ne voit que les personnes de ce cercle, pas le reste de la famille. S'il ajoute ou modifie leurs entrées, quand vous importez son fichier vous voyez les modifications et c'est vous qui les confirmez. Tous les détails sont dans la politique de confidentialité.

La sauvegarde avec les photos est volumineuse : comment l'enregistrer ?

À partir de la version 1.1, la sauvegarde peut aussi contenir les photos des certificats et des cartes, et le fichier peut devenir volumineux.

  • Avec « Partager la sauvegarde », vous choisissez où la mettre : Fichiers, un dossier cloud, un message.
  • Ou bien retirez les photos avec l'interrupteur : le fichier devient petit et chacun garde ses photos sur son propre téléphone.
Comment lire la puce de mon animal ?

À partir de la version 1.1. Ouvrez le profil de l'animal et passez en modification. À côté du numéro de puce, touchez le bouton pour le lire avec l'appareil photo et photographiez l'étiquette du passeport. Vérifiez ensuite le numéro lu. La photo sert uniquement à lire le numéro et n'est pas conservée.

Comment ajouter une ordonnance ?

À partir de la version 1.2. Allez dans « Ajouter au journal », « Ordonnance » et ajoutez les pages en les photographiant ou en important un PDF.

  • Medipop lit sur le téléphone, sans internet, le texte et les codes-barres, et propose la date, le médecin, le numéro de l'ordonnance, la validité et les médicaments qu'elle reconnaît. Rien n'est ajouté tant que vous n'avez pas confirmé.
  • Pour revoir le code-barres en grand sur l'écran, touchez « Afficher le code ».
  • À partir d'un médicament prescrit, « Créer le traitement » ouvre un traitement déjà rempli avec ce médicament. La dose et les horaires, c'est vous qui les saisissez : Medipop ne les calcule pas.
  • Vous pouvez partager l'ordonnance en PDF. Le PDF partagé n'est pas chiffré : celui qui le reçoit peut le lire.
  • Les ordonnances, avec leurs pages, sont dans les sauvegardes chiffrées comme le reste.

C'est une copie personnelle : qu'une pharmacie accepte ou non une copie dépend du pays et du type d'ordonnance. Gardez l'original.

Comment modifier un traitement ou changer la dose ?

À partir de la version 1.2. Dans le journal, ouvrez la fiche du traitement.

  • Touchez « Modifier » : vous pouvez tout changer, y compris la date de début, même avec des dates passées.
  • « Dernier jour » va de pair avec « Durée en jours ». Si vous le laissez vide, le traitement dure jusqu'à ce que vous l'arrêtiez.
  • Dans « Changements de dose », touchez « Changer la dose à partir d'un jour » : choisissez le jour, puis écrivez la dose, combien de fois par jour et à quelle heure. Par exemple, une dose qui augmente ou qui diminue. Vous pouvez aussi choisir un jour passé.
  • Cela reste un seul traitement : le journal montre une ligne pour chaque changement. Les rappels suivent les horaires en vigueur chaque jour.
  • La dose et les horaires, c'est vous qui les saisissez : Medipop ne les calcule pas et ne les propose pas, il enregistre ce que vous écrivez.
Comment ajouter un médicament à une maladie ?

À partir de la version 1.2. Ouvrez la fiche de la maladie : sous « Médicaments pour cette maladie », vous voyez les médicaments déjà ajoutés.

  • Touchez « Ajouter un médicament ». Vous pouvez l'ajouter à partir d'un jour ultérieur, qui est sa date de début.
  • Pour l'arrêter, choisissez à partir de quel jour : c'est son dernier jour.
Comment utiliser la pharmacie familiale ?

À partir de la version 1.2. Allez dans Plus, « Pharmacie familiale » et ajoutez une boîte. Vous pouvez saisir les données ou partir d'une photo : Medipop lit sur le téléphone, sans internet, le petit code carré imprimé sur la boîte (il indique le produit, la date d'expiration et le lot) et, en Italie, aussi le code-barres de la vignette de la pharmacie ; s'il ne trouve ni l'un ni l'autre, il essaie avec la date d'expiration imprimée. Vérifiez toujours ce qui a été lu avant d'enregistrer.

  • Pour chaque boîte : le médicament, à qui elle est (à toute la famille, à une personne ou à un animal), la date d'expiration, le lot, ce qu'il en reste, l'endroit où vous la rangez et, si vous le voulez, une photo.
  • La liste montre d'abord les boîtes expirées, puis celles qui expirent dans les 30 jours. Elles apparaissent aussi dans l'onglet « Aujourd'hui », sous « Bientôt expirés ».
  • Vous recevez un avis 30 jours avant l'expiration et un le jour même, avec un texte général qui ne nomme jamais le médicament. Vous pouvez le désactiver pour chaque boîte.
  • Depuis une boîte, touchez « Commencer un traitement ».
  • Les boîtes, avec leur photo, sont dans les sauvegardes chiffrées. Une boîte qui est à toute la famille n'est jamais dans une sauvegarde faite pour un cercle ; la boîte d'une personne ou d'un animal du cercle, si.
Comment lire la notice ?

Medipop ne contient aucune notice et n'a pas internet. Pour une boîte dont le code appartient à l'Italie, à la Suisse, à l'Espagne, à la France ou à un médicament autorisé pour toute l'UE, ouvrez la boîte et touchez « Notice (site officiel) » : le navigateur du téléphone s'ouvre sur le site officiel de l'agence des médicaments (AIFA, Swissmedic, AEMPS, la base de données publique française des médicaments, EMA). Avant de l'ouvrir, Medipop vous prévient que ce site verra la page demandée et votre adresse IP, comme tout site ; Medipop n'envoie rien d'autre.

Pour les codes allemands et autrichiens, il n'y a pas de bouton, car aucun site officiel n'est accessible à partir d'un tel code. Medipop n'explique pas à quoi sert un médicament : adressez-vous au médecin ou au pharmacien.
